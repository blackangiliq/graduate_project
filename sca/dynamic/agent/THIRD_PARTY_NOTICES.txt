and license texts, pinned archive URLs and verified integrity digests are in

The bridge sources are unmodified. observer.js contains this project's observation
hooks. Rebuild the combined agent from the repository root with:
  cd sca/dynamic/agent
  npm ci --ignore-scripts
  cd ../../..
  python -m sca.dynamic.build_agent

The observer does not alter TLS validation, root/integrity decisions, return
values, request headers, or remote services. It records actual runtime evidence
from the selected local Android lab process.
